# Security reporting

Please report suspected vulnerabilities privately to **gabriel.klier@ufl.edu** with the subject **Klierly security report**. Include the affected version, a concise description, and reproduction steps using synthetic data. Do not send API keys, enrollment links, private course files, or other people's personal information.

Do not open a public issue containing vulnerability details. No response-time commitment or paid bounty program is offered at this stage. The project is an early preview; use the latest default branch and review deployment settings before exposing an instance.

Operational controls, recovery procedures and current limitations are documented in [security operations](docs/SECURITY_OPERATIONS.md). Tests and reviews reduce risk but cannot establish an absence of vulnerabilities.
