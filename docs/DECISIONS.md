# Progress and decision log

- **Stack**: Next.js 15 (App Router, server actions) + PostgreSQL 16 + Drizzle migrations; Python
  FastAPI worker for parsing and numerics; plain-JS MV3 extension. Three deployables, no more.
- **Retrieval**: PostgreSQL full-text search only. Embeddings deferred; nothing depends on them.
- **Jobs**: database-backed queue run inside the web process (`SKIP LOCKED`), not a separate broker.
  Fine for one instance; noted as a scaling item.
- **Suggestions are deterministic** (headings, "Module N:", objective lists, dated lines) and always
  reviewable, so the app never asserts course facts the files do not contain. AI topic proposals deferred.
- **Numeric truth lives in the worker.** The model must name a whitelisted calculation; its own
  arithmetic is never trusted, and the stored answer is the recomputed one.
- **Citations use short labels (S1…)** mapped server-side to chunk ids, so a model cannot cite
  something it was not given. Unverifiable quotes are downgraded and labelled, not shown as quotes.
- **Timed exams** keep answers ungraded server-side until submission; the browser never receives
  answer keys early.
- **Extension auth** is a revocable pairing token limited to two routes, with CORS for extension
  origins only — no host permissions, no cookies, no LMS credentials.
- **Presentation modes**: only "practice first" and "short reading first" are offered because only
  those are implemented.
- **Sample course** is generated by `fixtures/qmb-sample/build_fixtures.py` (fixed seed, statsmodels)
  and loaded through the real pipeline; loading fails if any quote or number does not check out.
- **Helpers**: two sub-agents were started for the worker and the extension and stopped early on an
  account spending limit; their partial files were reviewed, completed and tested by the lead.
- **Not done on purpose**: no deployment, no purchases, no domain, no accounts created anywhere.
